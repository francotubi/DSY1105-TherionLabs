# Ajustes finales de EV2

- Solo se listan los eventos creados por administración; se retiran los tres eventos antiguos de demostración.
- El administrativo puede eliminar eventos sin prospectos, con confirmación.
- Un evento con prospectos no se puede eliminar. El captador tampoco puede eliminar eventos.
- Se mantienen RUT único por evento, gestiones con responsable/fecha y protección de formularios.
- El proyecto se entrega sin archivos de pruebas unitarias ni instrumentadas.
- El funcionamiento sigue siendo local para EV2.

Extraer el ZIP en una carpeta nueva y abrir en Android Studio la carpeta que contiene directamente app y settings.gradle.kts. Las cuentas siguen siendo administrativo / Admin2026! y captador / Captador2026!.
