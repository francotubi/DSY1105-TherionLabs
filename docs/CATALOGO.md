# Catálogo de carreras

Consultado el 18/10/2026 en las páginas oficiales de las nueve escuelas de Duoc UC. Se identificaron 81 programas distintos enlazados desde esas páginas. No se declara que sea un catálogo exhaustivo ni que todas las opciones se impartan en cada sede. Incluye programas anunciados en la oferta publicada para el próximo proceso de admisión.

- https://www.duoc.cl/escuela/turismo/

La selección recoge interés, no confirma vacantes, admisión o disponibilidad por sede/jornada/modalidad. En EV3 este catálogo podrá sustituirse por datos validados y gestionados en el backend.

Otra / no la encuentro exige texto de 3 a 120 caracteres, cuenta como una de las tres preferencias y queda por confirmar. Se guarda separada del nombre de las opciones oficiales.
